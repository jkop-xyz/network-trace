## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for jkop-xyz/network-trace, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## Testing

On Windows, follow `docs/agents/windows-testing.md` to test a release against a real network and desktop and report the results as issues.
